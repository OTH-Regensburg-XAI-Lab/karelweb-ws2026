    Karel language reference

    Commands change the world; sensors return true or false without changing it. Directions are relative to Karel, except compass sensors. Beepers are shown as coins.

    Actions

    move();
    One square forward; requires a clear path.
    turnLeft();
    Rotate 90° left on the same square.
    pickBeeper();
    Take one coin here; requires a coin.
    putBeeper();
    Place one coin here; requires a coin in the bag.

    Path sensors

    frontIsClear() / frontIsBlocked()
    Accessible / blocked square ahead.
    leftIsClear() / leftIsBlocked()
    Accessible / blocked square to the left.
    rightIsClear() / rightIsBlocked()
    Accessible / blocked square to the right.

    Coin sensors

    beepersPresent() / noBeepersPresent()
    Current square contains a coin / is empty.
    beepersInBag() / noBeepersInBag()
    Bag contains a coin / is empty.

    Direction sensors

    facingNorth() / notFacingNorth()
    Facing / not facing north.
    facingEast() / notFacingEast()
    Facing / not facing east.
    facingSouth() / notFacingSouth()
    Facing / not facing south.
    facingWest() / notFacingWest()
    Facing / not facing west.

    Control flow

    if (condition) { ... } else { ... }
    Select a branch; else is optional.
    while (condition) { ... }
    Check before each repetition; may run zero times.
    for (int i = 0; i < 4; i++) { ... }
    Fixed repetition; replace 4 with a nonnegative integer. The counter cannot be used inside the loop.
    !frontIsClear()
    NOT: true when the condition is false.
    frontIsClear() && !beepersPresent()
    AND: both conditions must be true.
    leftIsBlocked() || rightIsBlocked()
    OR: at least one condition must be true. Precedence: ! then && then ||. Parentheses group conditions.

    Functions

    void helper() { ... }
    Define a function outside main and call it by name. The form void helper(void) is also supported.
    int main(void) { ... }
    Program entry; int main() is also valid. Finishing main ends the program. No return statement is needed or supported.
    helper();
    Functions can call themselves or each other recursively. Recursion needs a terminating case.

    Syntax and comments

    move();
    End each action or function call with a semicolon.
    { ... }
    Braces are required around function, branch and loop bodies. Blocks may be nested.
    // A line comment
    Explain your code until the end of the line.
    /* A block comment */
    Explain your code across one or more lines.

    This teaching language supports commands, conditions and parameterless functions. It does not support general variables, arithmetic, parameters or return values. There is no break, continue, do/while or switch. Conditions use the built-in sensors; custom predicate functions are not supported.
